## 🌟 Overview
**ToDoList-VanillaJS** is a clean, lightweight task management application built with pure JavaScript. It focuses on essential functionality and a distraction-free user experience, allowing users to organize their day without the bloat of heavy frameworks.

## ✨ Key Features
* **✅ Task Management:** Easily add, complete, and delete tasks with a single click.
* **💾 Local Storage:** Your tasks are saved locally in the browser, so they persist even after a refresh.
* **📱 Fully Responsive:** Optimized for a seamless experience on mobile, tablet, and desktop screens.
* **⚡ Instant Updates:** Real-time DOM manipulation for a fast and snappy interface.
* **🎨 Modern UI:** A sleek, user-friendly design with intuitive controls.

## 🚀 Installation
Follow these steps to get a local copy up and running:

1.  **Clone the Repository**
    ```bash
    git clone [https://github.com/ZakariaL-dev/ToDoList-VanillaJS.git](https://github.com/ZakariaL-dev/ToDoList-VanillaJS.git)
    ```
2.  **Navigate to the Project Directory**
    ```bash
    cd ToDoList-VanillaJS
    ```
3.  **Launch the App**
    Simply open the `index.html` file in your preferred browser:
    ```bash
    open index.html
    ```

## 📖 Usage
1.  **Add Task:** Type your task in the input field and press `Enter` or click the "Add" button.
2.  **Complete Task:** Click on the task text or the checkbox to toggle the "completed" state.
3.  **Delete Task:** Click the delete icon to permanently remove a task from your list.
4.  **Persistence:** Close your browser and come back later—your tasks will still be there!
